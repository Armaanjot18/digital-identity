📋 Procedure to Add File & Submission Requirements

Please review the upload constraints carefully before designing.

📦

Maximum File Size

The uploaded file must be a maximum of 50 MB. Files larger than 50 MB will be blocked automatically by the system.

✅

Allowed File Formats

Only standard image and document formats are accepted:

PNG JPEG JPG PDF
🚫

Disallowed Formats

Web code and vector formats are strictly not included:

HTML SVG WEBP
🏷️

Assigned School Code

File name must be uploaded with your assigned school code only (e.g., SCH-042_logo.png). Do not use personal names.

⚠️
MANDATORY PRESERVATION RULE:

The original image/file must NOT be deleted from your device after uploading. Maintain local copies on your laptop or drive until event results are officially declared.
